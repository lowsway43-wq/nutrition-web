NUTRIHEALTH - FULL FRONTEND PROJECT

Struktur:
- index.html      : struktur halaman
- css/style.css   : semua gaya/tampilan
- js/app.js       : interaksi dan perhitungan
- assets/         : gambar makanan lokal

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder NutriHealth_Full_Project di VS Code.
3. Jalankan index.html dengan Live Server, atau buka langsung di browser.
4. Jangan pindahkan index.html keluar dari folder ini karena file CSS, JS, dan gambar memakai path relatif.

Fitur frontend:
- Dashboard responsif
- Foto makanan
- Pencarian makanan
- Tambah/hapus makanan
- Perhitungan kalori dan makronutrien
- Target kalori
- Pelacak air
- Kalender

Catatan:
Ini masih frontend prototype. Data contoh belum tersimpan permanen, belum ada autentikasi,
database, API, atau backend. Setelah frontend berjalan, backend dapat disambungkan ke Laravel + MySQL.
Angka nutrisi hanya data contoh untuk demonstrasi.
